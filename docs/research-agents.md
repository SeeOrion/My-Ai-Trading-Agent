# 模拟交易研究 Agent

## 流程与边界

现有 Workflow 继续负责交易日历、每十分钟调度、账户隔离、候选池和基础评分。进入买入决策后，固定买入研究 Agent 在受限循环中自主选择行情、新闻、财务、资金流、因子或技术指标工具，决定继续补查或结束。它没有下单工具；所有动作只写模拟账本。

研究工具复用 `research_workspace` 的现有接口。A 股财务工具包含深度跟踪的财务报表；基金工具使用基金研究资料和基金新闻。数据缺失按缺失报告，不伪造财务、新闻或评分。当前港美股基本面供应能力有限，因此可能暂缓新买入。新闻工具不会嵌套调用另一轮新闻 LLM，避免重复消耗。

买入最终分为 0–100：基础分 × Workflow 权重 + 研究分 × Agent 权重。默认 60% / 40%，门槛 70。研究分由程序按事件可信度 35%、盈利持续性 35%、假设抗风险性 30% 计算；基础流程移除新闻情绪因子，研究提示词禁止再次按动量、估值或新闻情绪加分。维度划分减少重复计分，但不能保证模型推理完全独立。评分不是盈利概率，初始参数没有经过收益回测校准。

纪律、资金、仓位、风险预算、行情时效和结算条件独立执行。研究完成后和模拟成交前分别重取报价，默认有效期 300 秒、相对研究前价格偏移不超过 2%，并满足 Agent 给出的价格区间。重大/关键风险必须引用工具原文；当前明确规则为暂缓新买入。超时、失败、证据不足、轮数/预算耗尽、用量未报告均为独立状态，不生成替代评分，也不当作利空。

持仓检验按账户独立开关，默认关闭。先执行所有原有持仓止损止盈/纪律规则，再进行可选假设检验。仅完成且有附证据重大风险的“假设削弱＋减仓”或“假设失效＋退出”建议可以进入后续规则审核。旧仓位没有买入研究假设时返回证据不足，不补造历史。关闭后不查询持仓研究工具、不调用模型、不复用历史建议；运行中关闭会取消等待，在应用结果的数据库事务内再次核对配置版本。关闭不撤销已完成交易。

## 账户配置与界面

入口：模拟持仓 → AI 模拟账户 → 账户设置 → 本账户研究 Agent。可在手动模拟运行期间打开设置，并使用“立即关闭持仓检验”。设置和审计按账户 ID 隔离，不需要新增环境变量或重新填写密钥。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| position_enabled | false | 可选持仓检验 |
| workflow_weight / research_weight | 0.6 / 0.4 | 两项之和必须为 1 |
| entry_threshold | 70 | 综合评分门槛 |
| holding_days | 20 | 研究预期持有周期 |
| validity_seconds | 300 | 研究与报价有效期 |
| max_price_move | 0.02 | 允许价格偏移 |
| rounds | 5 | 单次研究最多模型轮数 |
| tokens | 16000 | 累计输入输出预算；请求前保守估计输入 |
| timeout_seconds | 45 | 单次研究超时 |
| repeated_queries | 1 | 相同工具参数查询上限 |

保存任何研究配置都会递增版本，使旧版本结果失效。工具仅绑定当前标的，禁止任意 URL 或模型指定其他账户。用量统计新增“买入研究”“持仓检验”；研究审计保留结构化回答与证据，但不保存 API Key。

路径除前端外均相对于 `backend/src/ai_trading_agent/`。

迁移 `20261110_01` 增加 `agent_accounts` 与 `agent_audits`；旧账户回填默认配置（持仓检验关闭）。不修改旧交易与资金。审计包含模型步骤、工具参数/时间/证据、结构化报告、权重、评分、规则审核和动作。成功买入通过 position_id 关联原假设。模拟买入与 Agent 卖出的现金、持仓、交易及最终审计更新处于同一数据库事务。

API：`GET/PUT /api/v1/ai-simulation/accounts/{id}/agent-settings`；`GET /api/v1/ai-simulation/accounts/{id}/agent-audits` 返回最近 50 条。总览候选预览仍是基础规则筛选，不是已经通过研究的买入批准。

## 验证与限制

自动测试覆盖加权评分、纪律优先、失效报价、失败暂缓、工具循环与重复查询、关闭零调用、运行中关闭取消。`backend/scripts/verify_research_agents.py` 仅允许运行在指定临时测试库，验证旧账户迁移、账户配置 API、买入假设关联、事务失败回滚、旧版本拒绝、关闭后不卖出和开启后受规则约束卖出。测试使用确定性模型/行情替身，不代表已验证真实供应商数据质量或策略收益。

证据校验能验证引用存在、工具类别和风险原文匹配，不能证明新闻真实或保证模型判断正确。证据文本有长度上限，缺失和截断需由模型显式报告。程序异常退出可能留下“研究中”审计，这不构成批准交易。部署仍按现有单后端进程调度；多实例扩容需要统一调度锁。
